Ann Display Website Replica
Overview

A single-page replica of Ann Display built using HTML, CSS, and vanilla JavaScript.

Features
9-slide image slider with automatic transitions and navigation.
Reuses images from the /image folder.
Displays Kannada text and custom content on specific slides.
Uses TANK_IMAGE.jpg for slides 4–7 and 03.jpg for slide 9.
Integrates a POST API to display dynamic response data on relevant slides.

How to Run

Open index.html using a local development server, such as VS Code Live Server.

Note

API functionality depends on server availability and proper CORS configuration.
